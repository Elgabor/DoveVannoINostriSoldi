# Codice di condotta

Questo repository è un progetto civico sui dati pubblici. Contribuisci con
rispetto, in modo verificabile, senza trasformare un numero in un'accusa.

## Comportamento atteso

- Discuti i dati con fonte, periodo e limiti visibili.
- Distingui un segnale da una colpa.
- Accetta una correzione quando la fonte o il contratto lo richiedono.
- Non pubblicare dati personali, credenziali o dettagli sfruttabili di una
  vulnerabilità non ancora corretta.

## Comportamento inaccettabile

- Molestie, insulti o attacchi personali.
- Pubblicare in una issue, una PR o una chat dettagli che permettono di
  sfruttare una vulnerabilità ancora aperta.
- Inventare numeri, fonti o responsabilità individuale.

## Segnalazioni

Per il comportamento nella community apri una issue pubblica, senza includere
dettagli di sicurezza.

Per una vulnerabilità non ancora corretta non aprire una issue. Usa il canale
privato descritto in [SECURITY.md](SECURITY.md):
https://github.com/Italian-Builders-Org/DoveVannoINostriSoldi/security/advisories/new
