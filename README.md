# Trasparenza Italia

> Dove vanno i soldi pubblici, fonte per fonte.

Trasparenza Italia è un progetto civico open source per rendere leggibili, ricercabili e confrontabili i dati pubblici sulla spesa e sulla gestione delle risorse della Pubblica Amministrazione italiana.

Il repository è in fase di avvio. L'obiettivo è aggregare esclusivamente fonti pubbliche verificabili, mostrando sempre provenienza, data di aggiornamento e limiti del dato.
